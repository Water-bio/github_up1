# 复合微生物载体性能预测平台（原型）

>大学生创新创业项目 · 微生物载菌材料智能优化

## 项目简介:
本项目面向复杂环境水处理中的微生物复合载体研发，构建"配方 → 性能"的机器学习预测模型，并开发交互式Web界面，用于预测不同制备参数下复合载体的净化性能（如COD去除率）。将机器学习方法引入微生物载体材料研发，实现从"经验试错"向"数据驱动"的转变，

当前仓库为**前期原型代码**,包含：
- 数据读取与预处理（pandas）
- 随机森林性能预测模型（scikit-learn）
- COD去除率预测交互界面（Streamlit）
- 实验数据可视化（折线图、PCoA图等）
> ⚠️ 仓库内示例数据为模拟生成数据，仅用于功能演示，非正式实验数据。

```bash
# 1.安装依赖
pip install -r requirements.txt
# 2. 运行预测界面
streamlit run app.py

功能演示：
• 上传/读取实验数据（Excel或CSV）
• 输入制备参数，预测COD去除率
• 绘制温度-去除率折线图
• 微生物群落PCoA图绘制（R脚本见 r_analysis.R）
